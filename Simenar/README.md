# Product Inventory and Expiration Detection System

## About the Project
An intelligent inventory management system developed as part of an academic seminar project.

The system uses image processing and text recognition technologies to identify products, scan barcodes, and detect expiration dates, helping improve inventory tracking and product management.

## Main Features
- **Barcode Detection:** Identifying products using barcode scanning.
- **Expiration Date Recognition:** Extracting expiration dates using OCR.
- **Product Identification:** Processing product information through a camera-based system.
- **Inventory Management:** Supporting the identification and monitoring of products and their expiration dates.

## Technologies Used
- Python
- ZBar – Barcode Detection
- OCR – Optical Character Recognition
- Image Processing

## Project Evaluation
The system was evaluated using 32 test cases.

| Component | Results |
|---|---:|
| Barcode Detection (ZBar) | 32/32 (100%) |
| OCR Recognition | 24/32 (75%) |
| F-score | 0.90 |
